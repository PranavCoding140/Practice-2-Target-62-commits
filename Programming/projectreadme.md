This project is a Random Quiz Generator. In this project a website is created which generates a 5 question quiz on a specific topic, difficulty assigned from level 1 to 5, given level 1 is the easiest and level5 containing advanced level questions on that topic. This project consists of HTML+CSS and JavaScript as frontend, and Java Business Logic Architecture embedded inside it. This project uses HTTP Servlet and request-response protocol, event-driven Programming, Current State Management, etc. to run the program and the website. I have made use of Hashsets, get-post methods, exception handling, Integer Parsing and many more similar Object-Oriented, Java Business Logic Architecture concepts to build this Project Prototype to be developed and added more features into it in the near future.
